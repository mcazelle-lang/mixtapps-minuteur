# 🍅 Minuteur Pomodoro

Travaille 25 minutes, souffle 5 : un minuteur Pomodoro épuré avec pause longue tous les 4 cycles, bip de fin et temps restant dans l’onglet.

- **Essayer** : https://mixtapps-demos.web.app/minuteur/
- **Sur Mixtapps** : https://mixtapps.com/u/mr-basic/EWg7XdW3NRLh0xvmsFsb (app de démonstration du compte Mr Basic)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
